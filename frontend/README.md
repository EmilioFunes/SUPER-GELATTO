# 🎨 Documentación del Frontend - Super Gelatto

Este documento detalla los procesos creativos y técnicos utilizados para el desarrollo de los activos visuales y experiencias interactivas del frontend.

## ✨ Recursos y Activos Visuales

### 🎬 Animación de Frames
La animación por frames (secuencia de imágenes) fue desarrollada utilizando **Flow**.
- **Proceso**: Se generó un video base en Flow, el cual fue procesado a través de un conversor de frames para obtener la secuencia de imágenes individuales que permiten la animación fluida en la web.

### 🔄 Experiencia 360°
La funcionalidad de visualización 360° se apoyó en herramientas de IA generativa web.
- **Proceso**: Se utilizó la plataforma web **TRIPO AI** donde, mediante *prompts* específicos, se generó el entorno/modelo 360. Los elementos resultantes fueron descargados e integrados en el proyecto, donde **Antigravity** se encargó de adaptar el código y la lógica para su correcto funcionamiento dentro de la aplicación.

### 🍦 Imágenes de Productos
Todas las imágenes de los productos (helados, toppings, etc.) presentadas en la aplicación fueron creadas artificialmente.
- **Herramienta**: **IA de Gemini**. Se utilizaron prompts detallados para mantener una estética coherente, premium y apetecible en todo el catálogo.

### 🍯 Efecto de Arequipe Deritiéndose
El fondo dinámico que muestra arequipe deritiéndose no es una animación generada por código puro.
- **Implementación**: Se trata de un **video en alta resolución** optimizado que se utiliza como fondo dinámico (`background-video`) para aportar realismo y una sensación artesanal a la interfaz.
