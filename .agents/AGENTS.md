# Reglas del Proyecto Super Gelatto

- **Apertura de Navegador/Web App**: Cuando el usuario pida abrir la página web o cuando se abra en un hosting/entorno local, abrir siempre desde la ruta del login (`/login`) en lugar del home (`/`).
- **Formulario de Login Limpio**: En la página de login (`/login`), los campos de correo electrónico y contraseña nunca deben tener valores o credenciales por defecto o autocompletadas (deben permanecer vacíos `""` inicialmente).
